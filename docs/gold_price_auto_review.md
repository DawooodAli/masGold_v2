## D. Semantic evidence

Official [API documentation](https://goldtimo.com/eg/en/docs) explicitly documents
Egyptian-market EGP gram buy/sell, gold karats 18/21/24, and endpoints
`/api/v1/price/XAU/EGP/{karat}`. The ounce `price` and `unit: oz` coexist with
per-gram `gramBuy` and `gramSell`; do not convert gram fields from ounces.

The official [gold explanation](https://goldtimo.com/eg/en/gold) identifies sell
as the customer selling to a dealer and buy as the customer's purchase price.
The fixed mapping in GoldTimoProvider._normalize is therefore:

- gramSell -> SHOP_BUY: shop buys from customer.
- gramBuy -> SHOP_SELL: shop sells to customer.

This links the API field names to the provider's public explanation; the API
field table itself does not independently define the counterparty. Obtain
provider clarification if its contract differs. Never infer direction from
which number is larger; reversed spreads are rejected, never swapped.
